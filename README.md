# FinTrack Personal Finance

A static personal finance management website built with HTML, CSS, and JavaScript.

## Features

- Login and registration with local browser storage
- Dev admin account
- Dashboard summaries and charts
- Transaction CRUD with search and filters
- Budget tracking and alerts
- Saving goals
- Reports with date filters
- Account management

## Run Locally

Open `index.html` in a browser, or run a local static server:

```bash
python -m http.server 8000
```

Then visit `http://127.0.0.1:8000`.
